第二个版本（0.1.1）。0.1.0 之后又攒了一批体验改动，这一版把它们收口了。

## 这一版新增

- **前端可以热更了**：以后改页面、改交互不用再重装 —— 开窗时会悄悄看一眼有没有新版，有就在右下角提一句，点一下换过去；万一新版起不来，下次开窗自动退回上一版，不会卡在空白页。
- **按话下载**：详情页每一话右边有个小按钮，只想存这一话就点它（鼠标移到那一行才露出来）；已经在本机的话打勾，标题上面那行写着整本离线了没（`整本已离线（12 话 · 320 MB）` / `已离线 3/12 话`）。
- **磁盘账本**：设置页能看缓存 / 离线副本 / 用户数据各占多少、这块盘还剩多少，还能摊开看「磁盘上有哪几话」；「我的下载」页顶部也有一行总量。
- **导出 / 导入**：收藏、阅读记录、设置能导成一个 JSON，换机器 / 重装 / 备份用得上（图片不导，那是再生资源）。
- **最近阅读能删了**：每条右上角一个 ✕，页头有「清空记录」（只动最近阅读，收藏和下载不受影响）。
- **下载看得见速度**：我的下载页显示速度与剩余时间。
- **桌面集成**：记住窗口位置与大小；下载完成 / 出错弹系统通知；托盘图标；开机自启；全局快捷键（默认 `Ctrl+Alt+G` 显示 / 隐藏窗口）—— 都在设置页里开关，同一页能看到托盘起没起、快捷键注册上没有。
- **设置页重生**：表单由后端那张配置表生成（以后加配置项不用改前端），新增「更新 / 磁盘 / 数据 / 日志 / 桌面集成」五块。

## 这一版修好的

- 点进详情再点「返回」，回到的是**原来那一页**：列表的页码与滚动位置都在（搜索页同理，关键词写进地址栏）。
- 详情页的作者名、标签能点，一下按它重搜。
- 阅读器那两条工具栏按指针位置**分开唤**（靠上只亮上面、靠下只亮下面，中间不闪）；工具条与浮层改成实底，不再糊着底下的漫画。
- 章节列表提到「相关作品」前面；章节多时能折叠，还能一键跳到上次读到的那话。
- 「下载这一话」不会再把你已经存好的本子名抹成 `漫画 422866`。

## 怎么用

下载 `GuzhuComic-0.1.1-win64.zip` → 解压 → 双击 `GuzhuComic.exe`。免安装、不要管理员权限、不需要 Python / Node / 科学上网；数据只在自己机器的 `C:\Users\<用户名>\.jmreader`。第一次运行 SmartScreen 会提示「未知发布者」（没买签名），点「更多信息 → 仍要运行」即可。
