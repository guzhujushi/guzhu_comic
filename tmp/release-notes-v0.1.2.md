第三个版本（0.1.2）。0.1.1 之后又攒了一批：修掉阅读器一个挺烦人的老毛病，补上几处手机上够不着 /
不方便的操作。（这一版的前端早就上线到热更通道了 —— 已经在用 0.1.1 的话，开窗点一下右下角那句提示
就能换过去，不用重装。）

## 这一版新增

- **阅读器破图能自愈**：网不好时那种半截图、403，现在会自己重试（先快后慢两档），没出来之前留一个
  虚线占位而不是空白；顶栏还有一颗「手动刷新」，想立刻重来就点它。整本下载完成之后，本话会自己
  重新拉一遍 —— 不用退出重进。
- **搜索页会折叠**：一次搜出十几二十部的时候，先铺 12 张，剩下的点「展开全部」再看，不会一屏刷不完。
- **搜索框会联想**：打字时按**本机数据**给候选（最近搜过的 + 收藏 / 看过的标题），`↑↓` 选、回车采用。
  不联网、不上传。
- **快捷键面板 + 一键防社死**：按 `?`（或 `F1`）列出所有快捷键；有人走过来就按 `P` —— 整窗盖住、
  自动滚屏停下、顺手落一次阅读进度，再按一次恢复。
- **触屏手势向桌面看齐**：左右滑翻页、边缘横滑切上下一话、中间双击放大到两倍宽。
  （手机版还多一颗「遮罩」按钮，桌面上没有它 —— 键盘按 `P` 就行。）
- **空状态不再是那个方头像**：收藏 / 搜索 / 下载为空时，用的是和开场闪屏同一份笔迹的品牌字标。

## 这一版修好的

- **本地服务加了通行证**：之前同机任何程序都能直接读走你的图片缓存和下载目录（实测过），
  现在取图、下东西都要带这次开窗的 token 才行。
- **打包版整页没数据**：0.1.1 那个壳没这毛病，是这次换桥带出来的回归，修好了。
- 整页图被打散的还原收口到后端一处（手机版之前读不出来，顺带统一了）。

## 怎么用

下载 `GuzhuComic-0.1.2-win64.zip` → 解压 → 双击 `GuzhuComic.exe`。免安装、不要管理员权限、
不需要 Python / Node / 科学上网；数据只在自己机器的 `C:\Users\<用户名>\.jmreader`。
第一次运行 SmartScreen 会提示「未知发布者」（没买签名），点「更多信息 → 仍要运行」即可。
