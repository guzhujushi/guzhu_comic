## 怎么跑出这份输出

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_android.ps1 :app:assembleFullDebug
& $adb install -r android\app\build\outputs\apk\full\debug\app-full-debug.apk
& $adb logcat -c
& $adb shell am start -n cn.guzhujushi.comic/cn.guzhujushi.comic.MainActivity --ez guzhu.probe true
Start-Sleep -Seconds 150          # 探针里有真网络请求，全程约 12~60s
& $adb logcat -d -v time -s python.stdout:* GuzhuShell:* | Out-File tmp\_probe_run.log -Encoding utf8
```

设备：`emulator-5554`（`sdk_gphone64_x86_64`）——
`ro.dalvik.vm.native.bridge = libndk_translation.so`、`ro.product.cpu.abilist = x86_64,arm64-v8a`
（**arm64 的包装得进、跑得起来**）。

## 逐条读法

| 步 | 验的 | 结果 | 判读 |
|---|---|---|---|
| 1 | 平台 | OK `machine=x86_64 python=3.13.16` | 翻译层下 `machine()` 仍报 x86_64（内核是 x86_64），**正常，不代表跑的是 x86_64 代码** |
| 2 | `cffi`（C ABI 那关，T1-b） | OK `cffi=1.17.1 backend=1.17.1` | 安卓上只有 cffi 1.17.1（没有 2.x 轮子），必须是它 |
| 3 | `curl_cffi`（T1） | OK `0.16.3`，载入 1.4s | **arm64 的 `_wrapper.abi3.so` 在翻译层里载入成功**，而且和 cffi 1.17.1 的 ABI 对得上 |
| 4 | HTTPS + TLS 指纹 | OK `impersonate="chrome"` → 200 | FFI 调用路径 + TLS 指纹路径都通了（打的是 CDN 站点，不依赖图源可达） |
| 5 | `jmcomic` 建客户端（T2） | OK，真拉 `/setting`，域名自动 2.1.7 → 2.1.11 | Pillow / pycryptodome 那组版本在安卓上够 jmcomic 起得来 |
| 6 | 拉一部详情 | OK 真作品 `422866` | 业务接口在端上可用 |
| 7 | 取一话的图片地址 | OK 图数 2，首图 `...00001.webp` | 注意：**图源现在发的是 webp** |
| 8 | 下一张图 | OK 200，**218,914 B**，文件头 `RIFF` | 真下到了字节 |
| 9 | Pillow 解码 | **FAIL** `UnidentifiedImageError` | **Chaquopy 的 Pillow 轮子不带 libwebp**（见下，**这不是零影响**） |
| 10 | Pillow 格式清单 | OK `webp=False jpeg=True png=True`（67 个扩展名） | 把第 9 步的病因钉死：不是文件坏，是解不了 webp |
| 11 | 系统解码器解扰真图（P1 加的一步） | OK `num=10`，218,914 B → 307,042 B、0.4s | 走 `BitmapFactory`/`Canvas`，**这就是 P1 的修法** |

**第 9 步当初被写成「可以先不管」，这条是错的（2026-10-15 夜更正）**：桌面同版本 Pillow 的
`features.check('webp')` 是 `True`，那是**安卓轮子自己的编法问题**没错 —— 但结论不能推成「本 app 用不到 PIL」。
jmcomic 的下载器**每张图都会走 PIL**（`open_image()` 是当实参先算出来的，`num==0` 也躲不掉），
图源发的又正是 webp → **安卓上每张图都下不来，而且异常被吞掉、日志里看不出任何东西**。
**修法见 `tmp/整页图解扰设计.md`**：下载时只落原图（`decode_image=False`，不碰 PIL），解扰自己来做，
安卓那半边用系统解码器（本表第 11 步就是它）。

**别拿这份输出当"安卓版成了"**：它只验依赖与链路。真机只剩 T3~T6（长图渲染上限 / 一话 200 张图内存 /
前台服务保活 / 毛玻璃掉帧），而"手机上自己点着用"还差 **P0**（把 `js_api` 换成带 token 的本地 HTTP 桥）。
