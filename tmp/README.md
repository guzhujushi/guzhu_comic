## `tmp/` 里的脚本（不是文档，别当资料读）

- `_runchecks.py` —— **回归入口**：把 `_check_*.py` 顺序跑一遍（exe 那几支要出包，默认跳过）。
- `_check_*.py`（30 支）—— 每支盯一个面：桥协议 / 静态服务 / 图片服务 / 解扰 / 更新与发布通道 / 单实例 / 日志 / 足迹 /
  页面结构与交互（无头 Chrome + 假桥）。每支的用法写在它自己的 docstring 头几行。
- `_probe_*.py` —— 真窗口探针（真 pywebview + 真 `API()`，读 DOM 回报）；`_shot_*.py` —— 无头截图，产物落 `_ui/`。
- `_net_*.py` —— 直连图源的端到端小工具；`_vt_*.py` —— VirusTotal 扫描 / 查询；`_gh_release.py` —— 发布 GitHub release。
- `_pc_bridge.js` / `_pc_bridge_server.py` —— 假桥 + PC 上的假前端（手机尺寸），P0 之前那块预演出来的，**没有任何鉴权、只许监听 127.0.0.1、只许临时跑**。
- `_flip_dev.py` —— 翻转 `config.yaml` 的 `dev.use_dev_server`（`_check_desktop_frozen.ps1` 会调它）。
- `_probe_run.ps1` / `_probe_run.log` —— 拉安卓 logcat 的脚本与最近一次原始输出（`.log` 不进仓库）。
- 四个中文小脚本（`测试.py` / `清缓存.py` / `查询函数.py` / `测试http服务.py`）—— 手工排障用的草稿。
