# 安卓真机连接与调试操作手册（2026-10-15 起草）

> 用途：真正开工那天照这个做 —— 本文只讲**操作**（PC 怎么连手机、怎么验机、怎么装包、怎么排障）。
> 选型理由与工作量见 `tmp/安卓端技术栈调研.md`（§5 环境三层）与 `tmp/安卓版可行性评估.md`（难度 D1~D10、待实测 T1~T8）。
> **现状**：目前**还没有一台可用的测试机** —— 现在插着的那台华为 Mate 80 Pro 是 HarmonyOS 6、装不了 APK（§1 / §2）。

## 0. 三层前提，先别混

| 层 | 是什么 | 在哪 | 手机侧要做什么 |
|---|---|---|---|
| ① 构建 | JDK + Gradle + Android SDK + Chaquopy 插件，把 `backend/` + `frontend/dist` 打成 APK | **PC** | 什么都不用做 |
| ② 连接 / 调试 | `adb`：装包、看日志、`chrome://inspect` 调 WebView | PC ↔ 手机（USB 或无线） | 打开「开发者选项 → USB 调试」 |
| ③ 运行 | 装上去真跑：验图源连通、长图渲染、后台下载 | **一台 arm64 真机** | 提供设备 |

- **不需要 sshd**：sshd 是「把手机当远程服务器」的路子（Termux 里跑服务、从别处 ssh 上去）。我们这个场景是「PC 编、手机跑」，正规通道就是 `adb`。
- **不需要 root**，**手机上不装任何东西**。
- **模拟器顶不上真机**：`curl_cffi` 只有 `android_24_arm64_v8a` 轮子（`tmp/_check_android_so_align.py` 拆包实测过），x86_64 镜像在 pip 阶段就装不上；arm64 镜像跑在 x86 PC 上慢到没法调 UI。

## 1. 本机 USB 实测现状（2026-10-15，实机查询，非推测）

查询命令（PowerShell）：

```
Get-PnpDevice -PresentOnly | Where-Object { $_.Class -eq "WPD" -or $_.FriendlyName -match "ADB|HDC|MTP|Android|HUAWEI" } |
  Select-Object Status,Class,FriendlyName,InstanceId | Format-Table -AutoSize
Get-ChildItem "HKLM:\SYSTEM\CurrentControlSet\Enum\USB" | Where-Object { $_.PSChildName -match "12D1|2207" } |
  ForEach-Object { Get-ChildItem $_.PSPath | ForEach-Object { (Get-ItemProperty $_.PSPath).DeviceDesc } }
```

**A. 现在插着的设备**

| 项 | 值 |
|---|---|
| 名称 | `HUAWEI Mate 80 Pro`（手机自报，WPD 友好名） |
| 机身型号 | **`SGT-AL50`**（PnP `DeviceDesc`） |
| 实例 ID | `USB\VID_12D1&PID_1101\63Q0226627001321`（`VID_12D1` = 华为） |
| Windows 侧 | 类 `WPD` / 服务 `WUDFWpdMtp` / 状态 `OK` → 就是**普通 MTP 文件传输** |
| Host 侧描述 | **`HDC Device`** → 华为自家调试协议（只有 DevEco Studio 的 `hdc` 认），**不是 ADB** |
| 内部存储 | 「此电脑」里能直接进去，根目录名 `我的手机` |

内部存储根下只有这几项（鸿蒙那套布局，**没有 `Android/`**）：

```
Documents / Download / HO_DATA_EXT_MISC / Sounds / 图库
```

**B. 这台机器在 PC 上的全部 USB 历史（注册表 `Enum\USB`）**

| 实例 | 描述 | 服务 | 最后一次接入 |
|---|---|---|---|
| `USB\VID_12D1&PID_1101\63Q022…321` | `SGT-AL50` | `WUDFWpdMtp` | **现在就在**（2026-10-15） |
| `USB\VID_12D1&PID_107E\63Q022…321` | `HDC Device`（复合设备） | `usbccgp` | 2026-10-15 00:02 |
| `USB\VID_12D1&PID_107E&MI_00\…` | `MTP USB 设备` | `WUDFWpdMtp` | 2026-10-15 00:02 |
| `USB\VID_12D1&PID_107E&MI_01\…` | `USB 大容量存储设备` | `USBSTOR` | 2026-10-15 00:02 |
| `USB\VID_2207&PID_0011&MI_00\…` | **`iFlytek EBook R2`** | `WUDFWpdMtp` | 2026-07-22 |
| `USB\VID_2207&PID_0011&MI_01\…` | **`ADB Device`** | `WINUSB` | 2026-07-22 |

这张表直接读出两件事：

1. **华为这两次接入，一次 ADB 接口都没出现过**（只有 MTP + Mass Storage）→ 这台机器**从来没开过 USB 调试**；就算开了，华为鸿蒙线给的是 `hdc`，`adb devices` 也不会认。
2. **唯一被枚举成 `ADB Device` 的是那台讯飞墨水屏电子书**（`VID_2207` = Rockchip，arm64）→ 它当时开过 USB 调试，能当「验 T1 总闸」的备选（见 §2 / §8）。

**C. 为什么现在这台 Mate 80 Pro 当不了测试机**

1. **装不了 APK**：Mate 80 系列 2025-11-25 上市，**全线 HarmonyOS 6**；鸿蒙 5 / NEXT 起改用鸿蒙内核、去掉 Linux 内核，**只支持鸿蒙原生应用，不能原生运行 Android 应用**（官方口径：不属于 Android，不与 Android 应用兼容；第三方容器如「卓易通」「出境易」能跑，但那是别人的兼容层，不是我们的验收环境）。
2. **ADB 端点不存在**（见上表），也就没有 `adb install` 这条路。
3. **存储布局也是鸿蒙的**（`HO_DATA_EXT_MISC`、`图库`，没有 `Android/`）。

## 2. 怎么判定「一台手机能不能当测试机」

**合格**（全部满足）：

- 系统是 **Android**（含 HarmonyOS 4 / EMUI 这类基于 AOSP 的），**API 26+**（Android 8.0+）
- CPU 是 **arm64-v8a**
- 能打开「开发者选项 → USB 调试」（Android 11+ 还能用系统自带的「无线调试」）
- 空闲存储 ≥ 2 GB；允许装「未知来源」的包
- 建议用**较弱 / 较旧**那台做验收（低端机过关才算过关），主力机留到最后试手感

**不合格**：

- **HarmonyOS 5 / 6（纯血鸿蒙、NEXT 系）** —— 装不了 APK，且调试走 `hdc` 不走 `adb`
- x86 / 32 位机（`curl_cffi` 没有对应轮子）
- iOS（完全另一套，不在本项目范围内）

**只看插线就能看出来的特征**：设备管理器 / `Get-PnpDevice` 里出现 **`ADB Interface` 或 `ADB Device`** = 有戏；只出现 **`HDC Device`** 而没有 ADB 接口 = 大概率是鸿蒙 5+。

## 3. PC 侧要装什么（一次性，全在 PC）

| 项 | 现状（2026-10-15 实测） | 要做的 |
|---|---|---|
| Android Studio | **没装**（`C:\Program Files` 里没有，`LOCALAPPDATA\Android\Sdk` 也不存在） | 装（带来 SDK 管理器、`adb`、模拟器、内置 JDK） |
| Android SDK / `adb` / `gradle` | **都没装**（`ANDROID_HOME`、`ANDROID_SDK_ROOT` 都是空，`adb` 不在 PATH） | SDK Manager 里装 Platform 36 + Build-Tools + Platform-Tools + Cmdline-tools |
| Java | 只有 **Oracle JDK 26.0.1** | **别拿它跑 Gradle**：Android Studio 的 Gradle JDK 选 `Embedded JDK (JBR 21)` |
| NDK | 没装 | 先不装（Chaquopy 只装预编译 wheel，真需要再补 3~4 GB） |
| Python（构建机） | 仓库 `.venv` = 3.14.6 | 直接给 Chaquopy 的 `buildPython` 指过去（要跟 app 同 minor 版本） |

- 下载量：Android Studio ≈ 1.2 GB；几个 SDK 包合计 ≈ 3~6 GB；首次构建再拉 Gradle 发行包（~150 MB）+ AGP / AndroidX / Chaquopy 依赖（数百 MB）。
- **网络**：`dl.google.com` 国内一般能直连；Maven Central 有时慢；Chaquopy 自己的 pip 仓库（`chaquo.com`）国内不一定稳 → 建议给 Gradle 配上本机 **7890 代理**（`gradle.properties` 里的 `systemProp.http.proxyHost` / `systemProp.https.proxyHost`，或换国内镜像）。

## 4. 手机侧要开什么

1. 「设置 → 关于手机」连点**版本号 / 软件版本** 7 次 → 出现「开发者选项」。
2. 「设置 → 系统和更新 → 开发人员选项」→ 打开 **USB 调试**（HarmonyOS 4 / EMUI 上名字一样）。
3. 部分国产 ROM 还要额外打开：**USB 调试（安全设置）**（允许通过 USB 装应用、改权限，可能要登录厂商账号）、**USB 安装**；小米要开「USB 调试（安全）」，OPPO / vivo 有的要登录账号。
4. 插线时手机弹「USB 用途」→ 选**传输文件（MTP）**；只选「仅充电」时 PC 什么都看不到。
5. **无线调试**（Android 11+，可选）：开发者选项里打开「无线调试」→ 用配对码 `adb pair <ip>:<port>` → `adb connect <ip>:<port>`。适合不想一直插线；不需要 root、不需要 sshd。

## 5. 连上以后先跑这几条（验收设备）

```
adb devices -l                                   # 期望看到设备，状态是 device（不是 unauthorized / offline）
adb shell getprop ro.product.model               # 型号
adb shell getprop ro.product.cpu.abi             # 期望 arm64-v8a
adb shell getprop ro.build.version.sdk           # 期望 >= 26
adb shell getprop ro.build.version.release       # 系统版本号
adb shell getprop ro.product.manufacturer        # 厂商，看是不是 HarmonyOS 系
```

全过 = 这台机器可以进 P1。

## 6. 装包与调试

- **装包两条路**：
  - `adb install -r app-debug.apk`（推荐，能看到失败原因）
  - MTP 侧载：把 APK 拖进「此电脑 → 手机 → `我的手机/Download`」→ 手机文件管理器点它安装（要允许「未知来源」）。**这条路不需要 adb**，但看不到日志。
- **调前端**：壳里 `WebView.setWebContentsDebuggingEnabled(true)` → PC 上用 Chrome 打开 `chrome://inspect` → 直接调我们的页面（体验接近桌面 WebView2 的 DevTools）。
- **看日志**：

```
adb logcat -v time | Select-String -Pattern "python|chaquopy|AndroidRuntime|GuzhuComic"
```

- **卸载**：`adb uninstall <包名>`。

## 7. 排障表

| 现象 | 大概原因 | 怎么办 |
|---|---|---|
| `adb devices` 空的 | 没开 USB 调试 / 只选了「仅充电」/ 线只能充电 / 驱动没装 | 逐条查：① 开发者选项里的 USB 调试；② 弹窗选「传输文件」；③ 换线；④ 装厂商 USB 驱动或让 Windows 自己装 |
| 状态 `unauthorized` | 手机上没点「允许 USB 调试」 | 手机上点允许（勾「始终允许」）；不行就「撤销 USB 调试授权」→ 重插 |
| 状态 `offline` | `adb` 服务状态乱了 | `adb kill-server` → `adb start-server` |
| 设备是 `HDC Device`、没有 ADB 接口 | 华为鸿蒙 5/6 线 | 这台装不了 APK（§2），换机 |
| `adb install` 报 `INSTALL_FAILED_NO_MATCHING_ABIS` | APK 里没有这个机型的 ABI | 我们只出 `arm64-v8a`；先确认机器是 arm64 |
| 装上了但一打开就崩 | Python 侧缺依赖 / Chaquopy 初始化失败 | `adb logcat` 看 `AndroidRuntime` 与 Python 的 stderr |
| MTP 里看不到内部存储 | 同上「仅充电」 | 换模式 / 换线 |
| 无线调试连不上 | 手机与 PC 不在同一个 Wi-Fi / 配对码过期 | 弄到同一网段，重新配对 |
