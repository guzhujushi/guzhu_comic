孤竹漫画 · 安卓壳自检页

这一页只在两种时候露出来：启动过程中，或者 Python / 本地服务起不来。 正常起来之后，页面会自动切到 http://127.0.0.1:47753 上的真前端。

正常的启动链路

  • assets/web/ ──解包──▶ filesDir/dist（assets 是只读 zip，起服务读不了）
  • Chaquopy 起 CPython → android_boot.start() → backend/server.py 静态服务
  • WebView 加载 http://127.0.0.1:47753（页面与图片同源，localStorage 才留得住）
  • 返回键：页面能后退就后退，退到头再退出 App

构建版本线（2026-10-15）

  • AGP 9.4.0 + Gradle 9.8.1（Java 25 要求 Gradle ≥ 9.1、AGP 9.4 要求 ≥ 9.6）
  • Chaquopy 17.1.0 / CPython 3.13（轮子仓库只到 cp313）
  • minSdk 26 / compileSdk 37 / targetSdk 36
  • 两条变体：full（arm64-v8a，带 curl_cffi，回真机）与 ui（x86_64，不带 curl_cffi，只跑模拟器看界面）

起不来时看哪里

  • 屏幕底部那几行就是异常栈（Kotlin 侧）。
  • Python 侧的更全：adb logcat -s python.stdout python.stderr， 以及设备里的 filesDir/logs/app.log。

设计文档在仓库 tmp/：技术栈调研 / 可行性评估 / 真机连接与调试操作手册。 工作区说明见 android/README.md。
