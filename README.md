# guzhu_comic

无广告的桌面漫画阅读器。前端基于 Vite + TypeScript，后端基于 Python（[JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python)），通过 PyWebView 打包为桌面应用。

## 亮点

- **数据不出本地**：阅读记录、收藏、搜索记录、整本下载、章节图缓存全在 `~/.jmreader/` 里 —— 不登录、不注册、没有账号、没有遥测。除了图源服务器和本机 `127.0.0.1`，它不跟任何别的地方说话。清缓存也丢不了记录：记录在 `data/`，被清的只是能重下的缓存。
- **能反复读，越读越顺**：读过一遍的章节图就留在本地了，第二次打开是读本地文件（秒开）；整本下载之后断网照读。关窗、断网、图源抽风都只是"停一下"—— 下次开窗接着下、接着读，只补缺的。
- **接着上次看，少点两下**：左侧导航左下角常驻一张「继续阅读」卡（封面 + 读到第几页），点一下直接进阅读器、落回上次那一页；读过好几本时它认的是时间最近的那本。
- **退回去就落回原处**：点进详情再点「返回」，回来的不只是那一页的地址 —— 列表的页码和滚动位置都还在（会话内记忆；点导航栏换页则是新的一趟，从顶部看起）。详情页的作者名、标签也能点，一下按它重搜，不用回搜索框重新敲。
- **推荐是真算出来的**：把收藏过的 tag / 作者、搜过的词攒成一份本地画像再打分（作者命中 1.5 倍、30 天半衰、热度占三成兜底），首页和搜索页各铺一段「为你推荐」，卡片副标题写明"为什么推它"；画像还空着就老实退化成热门榜，不硬凑。**推荐本身不额外发请求**，全在本地算。
- **两种读法，都调得动**：连续滚动（条漫）与单页翻页随时切换，图片宽度、页间距、背景色、自动滚屏都能改，改完立即生效；键盘 `←` `→` `空格` `Home` `End` `M` `Esc` 全都能用。
- **无广告、无弹窗、没有"升级会员"**：界面上只有内容。论坛（全站评论流）也是只读、不需要登录。
- **现代桌面壳**：Windows 毛玻璃窗口（DWM 亚克力）、深浅双主题（切换时从点击处摊开一个圆）、封面 → 阅读器的共享元素转场、"网点"加载动效、键帽式快捷键提示。
- **坏一格不连累整页**：首屏分块加载，哪一块没拉下来就只降级成那一块的提示，并自己重试；窗口从后台切回来还会再补一次，不会停在空白页。
- **离线优先的阅读体验**：详情、章节、封面都有本地缓存，进详情页先把要读那一话的前几张下下来，一话看到 90% 就把下一话排上队。
- **更新不用重装**：装好之后前端（页面与素材）能自己热更 —— 打开窗口时悄悄查一眼，有新版就在右下角提一句，点一下就换过去，安装包一行都不动；万一那份改坏了没起得来，下次开窗自动退回上一版。

## 特性

- **搜索**：首页顶部有一个毛玻璃搜索入口（按 `/` 也能进），搜索页整页做成一整块毛玻璃，进去光标直接落在输入框上；搜索结果元数据本地缓存 1 小时；搜过的词存在本机（`data/app.db` 的 `search_log` 表），搜索页里留最近 12 条，点一下重搜、能单条删或一键清空；记着的次数与时间也是推荐算法的输入；关键词写进地址栏（`#/search?q=`），点进详情再返回就落回原来那次搜索的列表
- **热门榜单**：最上面三部做成弧形轮播（当前分类最火的三部）；下面一条分类标签条（全部 / 同人 / 单本 / 短篇 / 韩漫 / 美漫），当前那个标签和下面的面板同色连成一块；首页面板里按分类铺横条，**每个分类只铺一行**（一行放几张随宽度变），行头左边分类名、右边「更多」进该分类页；分类页同样有标签条与 hero（hero 换成该分类前三），下面铺该分类的整页列表与「加载更多」；翻到第几页会写进地址（`#/category?c=doujin&page=3`），点进详情再返回，页码与滚动位置都还在；日 / 周 / 月与排序两页共用，选择会记住
- **详情页**：封面、作者、标签、简介、热度数据（观看 / 喜欢 / 评论数）、发布日期与更新日期、可折叠的章节列表、相关作品；右侧是只读评论区（剧透默认盖住）；详情缓存 24 小时；作者名和标签都能点，一下按作者 / 标签重搜；章节行右边可以「只下这一话」（鼠标进那一行才露出来），磁盘上已经有的话打勾，标题上面一行写着整本离线了没（`整本已离线（12 话 · 320 MB）` / `已离线 3/12 话`）
- **开始 / 继续阅读**：详情页顶部按阅读记录显示「开始阅读」或「继续阅读 · 第 N 页」，上次读到的那一话在章节列表里描蓝
- **阅读器**：整屏沉浸，顶部一条细进度线常驻；连续滚动 / 单页翻页两种模式，支持键盘（←/→/空格/Home/End/↑/↓/PageUp/PageDown/Esc）与点击两侧翻页，点屏幕中间收放工具条；翻页时写进度，退出（返回按钮 / 关窗口）也会再确认一次；工具条与目录 / 设置浮层都是**实底、不做毛玻璃**（不糊底下的漫画图）
- **阅读工具栏**：上下两条，默认都藏起来，鼠标动一下才出来（滚轮 / 方向键不算），停手两秒多自己收起；上 / 下两条**分开唤** —— 指针靠近上边只亮上面那条、靠近下边只亮下面那条，从屏幕中间过来两条都不动（目录 / 设置浮层开着时也不抢）；上面只有返回和标题 + 页码，下面是上一话 / 目录 / 下一话 / 设置（自动滚屏开着时顶部多一个暂停键），按 `M` 也能手动唤出
- **目录与阅读设置**：目录是带编号的底部浮层（几百话也找得到，当前话高亮并自动滚到眼前），设置浮层里改阅读模式、背景色、图片宽度、页间距、自动滚屏，改完立即生效；自动滚屏开着时顶部会多出一个暂停键，滚轮一碰就停
- **话末续读**：一话读完在图末给一张「下一话 · 第 N 话」的大按钮（单页模式浮在最后一页上），换话后角落提示一句，不用自己摸回目录找
- **首页轮播**：当前榜单最火的三部做成横向大卡片，摆成弧形自己转（鼠标停上去就停），点两侧的转到中间、点中间那张才进详情
- **论坛**：全站评论流（只读，**不需要登录**），一条条往下翻、点「加载更多」接着要；每条评论下面挂一个「来自《本子名》」的封面条，点它直接进详情。标题是后台补的（先显示 `JM<id>`，拿到缓存里的详情标题再换掉），剧透评论默认糊住；翻页页码写进地址（`#/forum?page=2`），进详情再返回落回那一页
- **左侧导航**：固定侧栏 + 品牌，窗口窄了自动只剩图标，当前页的图标会变形；左下角是「继续阅读」卡（最近读过的那本 + 读到第几页，点一下接着看）与「关于」「设置」，再下面是主题开关
- **设置页**：`config.yaml` 里的常用项直接在窗口里改（表单由后端的配置表生成，加一个配置项不用写前端），带缓存占用显示与手动整理；还有磁盘账本（缓存 / 离线副本 / 用户数据各占多少、这块盘还剩多少，可摊开看"磁盘上有哪几话"）、日志尾巴与日志目录、收藏与阅读记录的导出导入、桌面集成的**实际**状态（托盘起没起 / 快捷键注册上没有），以及「更新」块（检查 / 立即更新 / 退回上一版 / 打开前端目录）
- **阅读进度**：本地持久化，属于用户数据，清缓存不会动它
- **本地收藏**：详情页右上角一颗心，点一下即收藏（失败会自己翻回来）；「收藏」页按收藏时间倒序列出，卡片角上能取消。存在本机 `data/app.db`，**与图源账号无关、不需要登录**，清缓存也不会丢；加收藏时顺手存一份 tag / 作者快照，推荐画像就用它
- **推荐**：首页面板第一段、搜索页结果下面各铺一段「为你推荐」—— 从周榜热度前 40 部里，用「收藏的 tag / 作者 + 搜过的词」攒出来的画像打分（作者命中 1.5 倍加成，热度占三成兜底），行头右边「换一批」接着翻；卡片副标题写清"为什么推它"（`同人 · 中文` / `作者：山田`）。画像空、或者候选里一个都没命中，就老实退化成热度排序并改标题为「热门推荐」。收藏与搜索的权重按 30 天半衰。全部在后端本地算：榜单走缓存、tag 读本地详情缓存，**推荐本身不额外发请求**；拉不到就整段不出现，不连累页面
- **已收藏角标**：收藏过的本子，在所有列卡片的地方（首页 hero 与分类横条、分类页、搜索页、推荐段、论坛的封面条）封面右上角都有一颗「已收藏」小标；**没收藏的卡片什么角标都不加**；收藏页整页都是收藏、卡片角上已经有删除按钮，那边不打
- **图片缓存**：章节图下载并解密到本地，二次打开秒加载、支持离线阅读
- **预加载**：列表（首页 / 搜索）先铺封面 + 标题，详情缓存随后在后台补；进详情页就先把要读那一话的前几张下下来；一话看到 90% 再把下一话的开头排上队（没有下一话就不预加载）。跑过的章节目录里本来就有，直接跳过；全是后台线程，不挡任何点击
- **整本下载 / 我的下载**：详情页「阅读」旁边一颗「下载」，整本离线存到本机（默认 `~/.jmreader/downloads`，路径写在配置里）；左侧导航「我的下载」页列出每本的状态（`已下载 3/12 话 · 读到第 5 页`——阅读进度跟「最近阅读」是同一个口径）、封面右上角进度角标、卡片下面「暂停 / 继续 / 删除」。关窗、断网、图源抖都只是"停一下"：下次开窗按已有进度接着下，只补缺的话与缺的图；下载过的章节阅读时直接读离线副本，不会再往缓存里下一遍，也永远不会被「整理缓存」删掉；每个任务还写着速度与剩余时间，页头一行是离线副本总共占多少、这块盘还剩多少
- **缓存管理**：上限默认 2G，后台定时按「最久没看过」整话清理，也能一键清空
- **窗口毛玻璃**：Windows 上窗口整体半透明，底层交给系统 DWM 画亚克力，桌面内容由系统模糊（`window.glass` 选 none / mica / acrylic / tabbed，`window.glass_opacity` 控透度）
- **加载与动效**：列表先铺骨架卡片（蓝色呼吸光晕 + 从右下扫到左上的光带），搜到 / 保存完的按钮图标会变形反馈；开窗不等图源连接（客户端后台预热），首屏某一块没拉下来只降级成那一块的提示并自动重试，窗口从后台回到前台时也会自己补一次，不会停在空白页
- **开场动画**：一点开是一层深色毛玻璃，底上「GuZhu」斜体字标一笔笔描出来（单线 SVG 描边，约 1.5 秒；斜度直接烙在路径坐标里，不吃系统字体），这段时间后台把首页那批数据排进图源队列；描完墨迹亮起一层辉光，顺势缩小飞进左上角，正好落在导航品牌位上（品牌行里「孤竹」两字换成字标，「漫画」留着，下面 `Guzhu Comic` 不动）。首页铺好就揭幕，最迟 `splash.max_ms` 硬揭；点一下或按 `Esc` 跳过，`prefers-reduced-motion` 直接跳过描字与飞入
- **视觉**：暗色分层取自 [Raycast 设计系统](https://github.com/VoltAgent/awesome-design-md)——表面阶梯（画布 → 卡片）配 1px 发丝线做层级，不靠投影；主操作用白底黑字，蓝色只给加载 / 焦点 / 阅读进度；阅读器设置里有键帽样式的快捷键提示

## 技术栈

| 层       | 技术                                              |
| -------- | ------------------------------------------------- |
| 前端     | Vite + HTML / CSS / TypeScript                    |
| 图标动效 | [morphicons](https://morphicons.com)（描边图标变形）+ [lucide](https://lucide.dev)（图标数据） |
| 设计系统 | [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 里的 Raycast DESIGN.md（暗色分层 + 发丝线 + 键帽） |
| 后端     | Python + [JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python) |
| 桌面封装 | PyWebView（Windows 下使用 WebView2/Chromium），窗口毛玻璃走 DWM 亚克力 |
| 前后端桥 | PyWebView `js_api` 直调（无 HTTP 中间层）          |
| 本地存储 | SQLite（`data/app.db` 阅读进度 + 本地收藏、`cache/cache.db` 接口元数据）+ 文件系统（`cache/images` 章节图） |
| 图片服务 | Python `http.server` 本地静态服务（127.0.0.1，端口随机） |

## 环境要求

- Windows 10 / 11（需 WebView2 运行时，Win11 自带）
- Python 3.12+
- Node.js 18+

## 快速开始

```bash
# 1. 安装 Python 依赖
pip install -r requirements.txt

# 2. 安装前端依赖
npm --prefix frontend install

# 3. 启动前端开发服务器（终端 1）
npm --prefix frontend run dev

# 4. 启动桌面应用（终端 2）
python main.py
```

`config.yaml` 里的 `dev.url` 就是窗口加载的地址，默认指向 Vite 开发服务器；前端 `npm run build` 之后也可以改成打包出来的 `dist/index.html`。

## 页面

| 页面     | 路由                            | 说明                                                     |
| -------- | ------------------------------- | -------------------------------------------------------- |
| 热门     | `#/popular`                     | 首页轮播（全部最火三部）+ 分类标签条 + 面板里第一段「为你推荐」+ 各分类一行（右边「更多」进分类页） |
| 分类     | `#/category?c=&page=`           | 某个分类的榜单页：hero 是该分类前三，下面是整页列表、「加载更多」；翻到第几页会写进地址，从详情返回落回那一页与原来的滚动位置 |
| 搜索     | `#/search?q=`                   | 关键词搜索，整页是一块毛玻璃外壳；最近搜索读的是数据库里那份记录，结果下面还有一段推荐；关键词写进地址栏，从详情返回 / 刷新都落回那次结果 |
| 论坛     | `#/forum?page=`                 | 全站评论流，只读不登录；每条评论挂一个进对应本子的封面条；翻页页码写进地址，返回落回那一页 |
| 最近阅读 | `#/history`                     | 一部漫画一条（取最近读的那一话），按时间倒序，点卡片进详情页 |
| 收藏     | `#/favorites`                   | 本地收藏，按收藏时间倒序，卡片角上可取消收藏              |
| 我的下载 | `#/downloads`                   | 整本离线下载：进度角标 + 暂停 / 继续 / 删除；副标题里的阅读进度跟「最近阅读」同源 |
| 设置     | `#/settings`                    | 改配置、看缓存占用、立即整理 / 清空缓存                  |
| 关于     | `#/about`                       | 应用说明：能干什么 / 怎么用 / 数据放在哪（左下角）        |
| 详情     | `#/album?id=`                   | 漫画信息 + 章节列表 + 开始 / 继续阅读；作者与标签可点，一下按它重搜 |
| 阅读器   | `#/read?photo_id=&album_id=`    | 连续滚动 / 单页翻页，翻页时写进度；上下两条工具条默认隐藏（实底、不做毛玻璃），鼠标晃动唤出，按指针在上边 / 下边只亮对应那条 |

列表页进详情再点「返回」是"回到原处"：地址、页码、滚动位置一起回来（记忆只在这一次会话里，刷新 / 重开窗口从头开始）；点左侧导航换页不算"退回去"，照旧从顶部看起。

## 数据与缓存

```text
%USERPROFILE%\.jmreader\
├── data\
│   └── app.db                # 用户数据：阅读进度（history）+ 本地收藏（favorite）+ 搜索记录（search_log）+ 下载任务（download_album / download_chapter）
├── downloads\                # 整本下载的离线副本（目录 = config.yaml 的 download.dir）
│   └── <album_id>\<photo_id>\
└── cache\
    ├── cache.db              # 接口元数据：搜索 / 榜单 / 详情 / 章节图列表
    └── images\<photo_id>\    # 章节图（已解密），一话一个目录
```

- `data/` 只在翻页 / 收藏 / 搜索时写入，清缓存 / 整理缓存都不会碰它。
- 推荐只读这三张本地表与本地详情缓存：画像每次现算、不落盘，不上传、不登录、也不额外发请求。
- `cache/` 里的东西全是可再生的：删掉只是下次重新请求、重新下载。
- 整本下载的离线副本在 `download.dir`（默认 `~/.jmreader/downloads`）里，既不属于 `data/` 也不属于 `cache/`：清缓存 / 整理缓存都不碰它，只有「我的下载」页的删除按钮会删它。
- 上限 `cache.max_size_mb` 默认 `2048`（2G），`0` 表示不限；占用按整个 `cache/` 目录算，设置页能看到当前用量。
- 后台线程每 `cache.cleanup_interval` 秒（默认 600）检查一次，超过上限就从最久没看过的章节开始**整话**删，一直压到上限的 90%；正在看的章节和正在下载的章节留到最后才删。

## 目录结构

```text
guzhu_comic/
├── main.py                 # 入口：读 config.yaml 开窗，把 API 挂成 js_api
├── config.yaml             # 配置（设置页读写）
├── backend/
│   ├── api.py              # 全部 js_api：搜索 / 榜单 / 详情 / 评论 / 章节图 / 下载 / 进度与收藏 / 推荐 / 缓存 / 磁盘与日志 / 更新 / 桌面集成
│   ├── config.py           # config.yaml 读写，缺的键用默认值补齐
│   ├── settings_spec.py    # 设置项的声明式表（设置页表单 + save_settings 校验都按它来）
│   ├── paths.py            # 目录常量（APP_DIR / DATA_DIR / CACHE_DIR / WEB_DIR …）
│   ├── server.py           # 本地静态服务（页面与图同源；热更覆盖层每请求重挑根）
│   ├── updater.py          # 前端热更新：查 manifest / 下载校验 / 白名单解压 / 整目录替换 + 自动回滚
│   ├── version.py          # 安装包版本 + 出厂前端构建号
│   ├── desktop.py          # 桌面集成：窗口几何记忆 / 通知 / 托盘 / 开机自启 / 全局快捷键 / 打开目录
│   ├── logging_setup.py    # 日志落盘（~/.jmreader/logs，按天切留 7 天）
│   └── glass.py            # Windows 窗口毛玻璃：DWM 亚克力 + 窗口透明度
└── frontend/
    └── src/
        ├── main.ts         # 导航 + 路由注册
        ├── router.ts       # hash 路由
        ├── settings.ts     # 前端读配置（进程内缓存一份）
        ├── webstatus.ts    # 等 pywebview 把桥注入好
        ├── prefetch.ts     # 后台预热：列表 -> 详情缓存，详情 / 阅读 -> 章节图
        ├── recommend.ts    # 推荐段（首页第一段 / 搜索页结果下方共用）
        ├── splash.ts       # 开场闪屏：揭幕时机 + 飞进左上角（画面本身内联在 index.html）
        ├── pywebview.d.ts  # js_api 的类型声明
        ├── pages/          # board（热门/分类共用）/ popular / category / search / forum / detail / reader / history / favorites / downloads / settings
        └── components/     # album-card（含「已收藏」角标）、album-list、recommend、hero、picker、states、icons
```
